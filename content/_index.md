symptoms:
- title: Printer shows offline
  text: The printer is powered on, but Windows marks it offline and holds every job.
- title: Jobs disappear or stick
  text: The queue shows a document that never prints, or jobs vanish and reappear.
- title: Wrong printer or driver
  text: The job goes to a virtual printer, a duplicate queue, or a driver that cannot use the printer.
checks:
- title: Clear the queue safely
  text: Cancel only the stuck test jobs and restart the print spooler. Record the job names before clearing.
- title: Confirm printer IP and port
  text: Print a network configuration page or use the printer panel. Compare its IP with the Windows printer port.
- title: Use the matching driver
  text: Remove duplicate queues and install the vendor driver for the model. A generic driver may print but lose features.
- title: Print a physical test page
  text: Send the Windows test page and confirm it comes out of the intended printer with correct alignment.

faqs:
- q: Why is it offline when it is on?
  a: Windows may be using the wrong port or a stale queue. The printer's IP and the configured port must match.
- q: Will clearing the queue lose jobs?
  a: Yes, the queued jobs are removed. We record them first and use a test page; reprint important jobs afterward.
- q: Can you fix a hardware fault?
  a: No. We isolate the Windows/queue/network path. Physical repair or supplies are outside scope.
